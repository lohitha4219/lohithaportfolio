
# Personal Portfolio Website

A modern, responsive personal portfolio built to showcase my skills, projects, education, experience, certifications, and professional journey as a Full Stack Developer.

## 🚀 Live Demo

https://lohithaportfolio-gray.vercel.app

## ✨ Features

- Modern and responsive user interface
- Dark and light mode
- Smooth animations and transitions
- Hero section with professional introduction
- About section
- Technical skills showcase
- Projects portfolio with working links
- Professional experience section
- Education details
- Resume viewing and downloading
- Certifications with certificate preview
- Contact section
- Social media integration
- Responsive navigation and footer

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript
- Framer Motion
- Lucide React

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/lohitha4219/lohithaportfolio.git
```

### 2. Navigate to the project folder

```bash
cd lohithaportfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```
